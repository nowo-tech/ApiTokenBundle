# ApiTokenBundle

Personal API tokens for Symfony: hashed lookup tokens with per-module grants, expiry, revocation, rate limits and an audit trail, a Bearer authenticator and a UiKit UI.

Standard Symfony by default, DDD / hexagonal opt-in, FrankenPHP worker-safe (kernel kept alive, no reset).
Composer package: `nowo-tech/api-token-bundle` (not released yet).

Work in progress: the package scaffold (S0) lands through a pull request. See `docs/ROADMAP.md` once it is merged.
